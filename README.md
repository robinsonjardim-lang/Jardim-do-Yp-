# Jardim do Ypê – Participação Ativa

Site responsivo para inscrições de moradores interessados em colaborar com o condomínio ou manifestar interesse em uma futura candidatura a subsíndico(a).

## Arquivos
- `index.html`: página principal e formulário.
- `css/style.css`: identidade visual e responsividade.
- `js/app.js`: validação e envio do formulário.
- `js/config.js`: credenciais públicas do Supabase (configurar antes de publicar).

## 1. Criar o banco no Supabase
1. Crie um projeto em https://supabase.com/.
2. No SQL Editor, execute:

```sql
create table public.participacoes (
  id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  nome text not null,
  torre text not null,
  apartamento text not null,
  email text not null,
  telefone text not null,
  tipo text not null,
  areas text[] not null,
  disponibilidade text,
  mensagem text,
  consentimento_em timestamptz not null
);

alter table public.participacoes enable row level security;

-- Permite somente inserir inscrições pelo site.
create policy "Permitir envio de participacoes"
on public.participacoes
for insert
to anon
with check (
  char_length(nome) between 2 and 120
  and char_length(email) between 5 and 160
  and char_length(telefone) between 8 and 30
  and cardinality(areas) >= 1
);

-- Não crie política pública de SELECT.
-- A leitura dos cadastros deve ficar restrita a usuários administrativos autenticados.
```

3. Em Project Settings > API, copie a Project URL e a chave `anon`/publishable.
4. Preencha `js/config.js`:

```js
window.SUPABASE_URL = "https://SEU-PROJETO.supabase.co";
window.SUPABASE_ANON_KEY = "SUA_CHAVE_PUBLICA";
```

**Nunca use a chave `service_role` no site.** Ela concede privilégios elevados e não pode ser publicada no GitHub.

## 2. Publicar no GitHub Pages
1. Crie um repositório público chamado `jardim-ype-participacao`.
2. Envie todos os arquivos mantendo as pastas.
3. No GitHub, acesse Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha `main` e `/ (root)` e salve.
6. Aguarde a publicação. O endereço será semelhante a `https://SEU-USUARIO.github.io/jardim-ype-participacao/`.

## 3. Administração dos cadastros
Os registros ficam no Supabase, não no navegador nem em uma planilha pública. Consulte-os pelo painel do Supabase, com acesso restrito aos responsáveis autorizados. Antes de criar um painel administrativo próprio, implemente autenticação, autorização por função e políticas RLS específicas para leitura.

## Privacidade e governança
- Publique um aviso de privacidade com a identificação do controlador, finalidade, base legal, prazo de retenção e canal para solicitações dos titulares.
- Colete apenas os dados realmente necessários e limite o acesso aos responsáveis autorizados.
- Não publique nomes, apartamentos, telefones ou candidaturas em páginas abertas.
- O cadastro de interesse não equivale a eleição ou nomeação. A escolha de ocupantes de cargos deve seguir a convenção e as deliberações aplicáveis ao condomínio.
- Faça testes com dados fictícios antes de divulgar o formulário aos moradores.

## Teste local
Abra `index.html` no navegador para conferir o layout. O envio só funcionará depois da configuração do Supabase e das políticas do banco.
